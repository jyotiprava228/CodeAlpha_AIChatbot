# CodeAlpha_AIChatbot
# AI Chatbot Using Java

### CodeAlpha Internship Project

## 📌 Project Overview

The **AI Chatbot** is a Java-based conversational application developed as part of the CodeAlpha Internship Program.

The chatbot interacts with users, accepts text-based questions, and provides relevant responses related to programming, artificial intelligence, machine learning, and technology.

The project demonstrates fundamental Java programming concepts and the development of a simple conversational system.

## 🎯 Objectives

- Develop a basic chatbot using Java.
- Understand conversational interaction between users and computers.
- Implement user input and automated responses.
- Improve Java programming and problem-solving skills.
- Explore the fundamentals of chatbot development.

## ✨ Features

- Interactive text-based conversation.
- Responds to user greetings.
- Answers basic questions about programming and technology.
- Provides responses related to Java, Python, AI, and machine learning.
- Simple and user-friendly interface.
- Supports continuous interaction with users.

## ⚙️ How to Run the Project

**Step 1: Clone the repository**

```bash
git clone https://github.com/jyotiprava228/CodeAlpha_AIChatbot.git
```

**Step 2: Open the project folder**

```bash
cd CodeAlpha_AIChatbot
```

**Step 3: Compile the Java program**

```bash
javac AIChatbot.java
```

**Step 4: Run the chatbot**

```bash
java AIChatbot
```
